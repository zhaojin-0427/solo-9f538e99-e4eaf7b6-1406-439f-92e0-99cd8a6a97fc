# 品种试验复核与效应比较

一季多点品种试验的网页工具：上传实收数据 → 拟合「试验点效应 + 品种效应」
最小二乘模型扣除点位差异 → 按所选顺序给出两个品种的品种效应之差。
支持复核时整点剔除/恢复，剔除后按新的有效关系重新判断可比性并重算；
支持按试验点下载当季称重单并按小区记录号整单更正实收克数。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

SQLite 数据库保存在名为 `trial-data` 的卷里（容器内 `/data/trial.db`）。
旧版本留下的同名卷会被原地升级（补季号/记录号/原始克数列并回填），
已有数据保留。

本地开发（Python 3.11+）：

```bash
pip install -r requirements.txt
python app.py            # http://localhost:8000
python tests/test_core.py  # 核心逻辑测试（不依赖 Flask）
```

## CSV 格式

### 整季上传

每行一个等面积小区：

```csv
季号,小区记录号,试验点,品种,实收克数
2026春,S1-101,S1,V1,1000
```

- 必填列：`试验点`、`品种`、`实收克数`（或 `site` / `variety` / `grams`）。
- 可选列：`季号`、`小区记录号`。缺省时季号为空、记录号按文件行号补齐，
  仍可在称重单中更正。一次上传只能包含一个季号。
- 同一试验点同一品种可有多行（多个小区），每行等权。
- 试验点最多 64 个，超出拒绝导入；同点同季记录号重复也拒绝导入。
- 上传为整季替换，失败则沿用原状态。UTF-8 / 带 BOM 均可。

### 称重单更正（按试验点）

1. 打开「称重单更正」，选择试验点，下载当季称重单 CSV：
   `季号,小区记录号,品种,原始克数,当前克数`。
2. 按同一试验点上传更正 CSV，每行四列：
   `季号,小区记录号,所见克数,新克数`。

整单校验，任何一行有问题都会标出行号与原因并**整单退回**，不改任何数据、
不改取数状态。检查项：

- 季号已过期（与当前明细不一致）；
- 小区记录号在文件内重复，或不属于所选试验点；
- 所见/新克数无效（空、非数字、非有限、负数）；
- 所见克数已变（当前克数 ≠ 提交的所见克数，防止基于旧单更正）。

全部通过后只更新当前克数，**原始克数始终保留**；下载页同时列出两者。
保存过程中的任何异常都整体回滚，原数据与取数状态照旧。

更正后的取数行为：

- 更正涉及**有效**（未剔除）试验点且值确有变化 → 沿用当前剔除名单生成
  新复核版本（复制组合快照并只调整受影响的小区合计），后台按最新克数重算；
  重算完成前，仍可比的品种对显示「待校正」。
- 只更正**已剔除**试验点 → 当前拟合结果保持不变；之后恢复该点时，
  新版本取数使用更正后的克数。
- 新克数与当前克数相同 → 数据不变，不生成新版本。

## 模型与可比性

- 模型：`产量 = 试验点效应 + 品种效应`，每行等权，最小二乘拟合。
  每个连通组内排序第一的试验点效应钉扎为 0（同组内品种效应之差与钉扎无关）。
- 可比较：两品种在同一**有效**试验点都种过，或经其他品种与有效试验点
  连通（点–品种二分图的同一连通组），否则不可比较。
- 比较结果按所选顺序给出：品种甲效应 − 品种乙效应（克）。

## 复核版本语义

- 复核页勾选剔除的试验点（取消勾选即恢复），提交生成新复核版本；
  保存失败整体回滚，沿用原状态。
- 提交后**可比性立即按新关系判断**；新版拟合未完成期间，仍可比的
  组合显示「待校正」；取数只采用当前复核版的拟合结果。
- 拟合在后台线程执行，拟合期间仍可提交复核（新版取代旧版，旧版标记
  「已被新版取代」）。
- 拟合失败：复核决定保留，页面提示并可一键「重算」。

## 内存规模

- 拟合不建完整设计矩阵：按 (试验点, 品种) 组合聚合计数与总和
  （O(实际组合数)），正规方程中品种块为对角阵，解析消去品种效应后只求解
  「试验点数 × 试验点数」的约简方程组（O(试验点数²)）。
  总内存随 实际组合数 + 试验点数² 增长。
- 每个复核版本在提交时保存有效组合合计快照（`version_plots`）。拟合与
  比较只读当前版本的快照，不扫描原始小区表；更正时只在新版本快照上
  调整受影响的小区合计。称重单更正本身只查所选试验点的小区明细。
