# 品种试验复核与效应比较

一季多点品种试验的网页工具：上传实收数据 → 拟合「试验点效应 + 品种效应」
最小二乘模型扣除点位差异 → 按所选顺序给出两个品种的品种效应之差。
支持复核时整点剔除/恢复，剔除后按新的有效关系重新判断可比性并重算。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

SQLite 数据库保存在名为 `trial-data` 的卷里（容器内 `/data/trial.db`）。

本地开发（Python 3.11+）：

```bash
pip install -r requirements.txt
python app.py            # http://localhost:8000
python tests/test_core.py  # 核心逻辑测试（不依赖 Flask）
```

## CSV 格式

每行一个等面积小区：`试验点,品种,实收克数`（也接受 `site,variety,grams` 表头，
UTF-8/带 BOM 均可）。同一试验点同一品种可有多行（多个小区），每行等权。
试验点最多 64 个，超出拒绝导入。上传为整季替换，失败则沿用原状态。

## 模型与可比性

- 模型：`产量 = 试验点效应 + 品种效应`，每行等权，最小二乘拟合。
  每个连通组内排序第一的试验点效应钉扎为 0（同组内品种效应之差与钉扎无关）。
- 可比较：两品种在同一**有效**试验点都种过，或经其他品种与有效试验点
  连通（点–品种二分图的同一连通组），否则不可比较。
- 比较结果按所选顺序给出：品种甲效应 − 品种乙效应（克）。

## 复核版本语义

- 复核页勾选剔除的试验点（取消勾选即恢复），提交生成新复核版本；
  保存失败整体回滚，沿用原状态。
- 提交后**可比性立即按新关系判断**；新版拟合未完成期间，仍可比的
  组合显示「待校正」；取数只采用当前复核版的拟合结果。
- 拟合在后台线程执行，拟合期间仍可提交复核（新版取代旧版，旧版标记
  「已被新版取代」）。
- 拟合失败：复核决定保留，页面提示并可一键「重算」。

## 内存规模

拟合不建完整设计矩阵：按 (试验点, 品种) 组合聚合计数与总和
（O(实际组合数)），正规方程中品种块为对角阵，解析消去品种效应后只求解
「试验点数 × 试验点数」的约简方程组（O(试验点数²)）。
总内存随 实际组合数 + 试验点数² 增长。

## 文件

| 文件 | 说明 |
| --- | --- |
| `fit.py` | 纯计算：连通组、最小二乘（消元+钉扎+回代） |
| `store.py` | SQLite：数据、复核版本、剔除集合、拟合状态机 |
| `csvio.py` | 上传 CSV 解析与校验 |
| `app.py` | Flask 路由与后台拟合线程 |

| `tests/test_core.py` | 核心逻辑测试（19 例） |
| `sample.csv` | 示例数据（含孤立品种与链式连通） |
